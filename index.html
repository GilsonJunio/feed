I've been quite pissed lately regarding all the issues with VSCodium and VSCode extensions. So i decided to try something: Installing VSCodium inside a container, and running a local git server for managing my website code files. I already did the first part: i ran distrobox create --name [container-name] --image registry.fedoraproject.org/fedora:latest --home [container-home-path] --additional-flags "--security-opt label=disable" --unshare-all Distrobox is a tool that allows running any Linux distro inside a container seamlessly integrated with my host, in other words, i can run GUI software inside any container without going through the pain of manually installing graphical tools inside the container.

  • --name Names the container
  • --image Pulls the image from the fedora repo
  • --home Sets the container home directory
  • "--security-opt label=disable" Disables SELinux for this container alone (Honestly i'm not sure if this helps at all actually, maybe this option is dismissable)
  • --unshare-all Creates a more isolated container, where only the $HOME, basic sockets and host’s FS (in /run/host) is shared
